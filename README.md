# Harmonic Analysis of IEEE Distribution Networks

## Overview

This repository contains models and preliminary analysis related to harmonic studies on IEEE 18- and 33-bus distribution networks. The study utilizes multiple power system simulation tools: ETAP 12.6.0, DIgSILENT PowerFactory 21, PSS®SINCAL 19.0, and PCFLO 6.0. The models applied in different software tools aim to compare the accuracy of harmonic distortion calculations.

⚠ **Note:** This research is currently under peer review for the 12th International Conference on Electrical, Electronic and Computing Engineering (IcETRAN 2025). The results and methodology are subject to updates based on the review process.

## Contents

* IEEE 18-bus and 33-bus models – Implementations for different simulation tools.
* Preliminary results – Initial findings from harmonic analysis.
* Scripts and configurations – Files used for simulations.

## Usage

1. Download the required model files.
2. Open them in the respective software tool (ETAP, DIgSILENT, SINCAL, or PCFLO).
3. Run the harmonic analysis and compare the outputs.
